# job-analytics

This project is a Job Market Analytics and Recommendation Platform that collects job postings from different sources, stores them in a database, and makes them easy to analyze and explore. We use Python for data collection and cleaning, PostgreSQL to organize and store job data, and analytics tools like pandas and matplotlib to find insights such as trending skills or in-demand roles. On top of this, we apply AI/NLP techniques (using libraries like spaCy or scikit-learn) to extract skills from job descriptions and match them with a user’s CV, helping recommend the most relevant jobs. The platform is presented through a simple frontend interface (using Streamlit for dashboards and filters), making it interactive and beginner-friendly. Overall, it combines data engineering, analytics, and AI into one collaborative project
